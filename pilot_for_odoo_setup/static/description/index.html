MCP Connector
for Odoo CRM.

Connect Claude Desktop, Claude Code, Cursor, or any Model Context Protocol client to your Odoo in two clicks. Generates an API key and a ready-to-paste configuration block.

What it does

Open Settings → MCP Connector → Setup wizard after install. The wizard auto-detects your Odoo URL, database, and login, generates a revocable API key on the current user, and renders the JSON configuration block you paste into your MCP client's settings file.

The generated API key works alongside two-factor authentication, which password-based XML-RPC does not.

Standalone, by design

This module is free and useful on its own. The generated key works with any MCP-compatible client — not only with the OdooPilot agent recommended below. You can also use the produced config as a template for building your own MCP integrations.

A ready-made MCP client (optional)

Don't have an MCP client yet? OdooPilot is a third-party AI agent for Odoo CRM built by equationx. It lives in Claude Desktop and answers questions like "give me the Monday brief" or "how is Alex doing this month?" in plain English, in 30 seconds.

OdooPilot is a separate paid product. This connector module works with any MCP client; OdooPilot is one option.
