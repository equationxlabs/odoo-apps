# equationx — Odoo Apps

Public repository of free Odoo Community Edition modules published by [equationx](https://equationx.ai).

Each top-level folder is a separate module. Branches correspond to Odoo
series (one branch per supported version, per the Odoo Apps Marketplace
convention).

## Modules

### `pilot_for_odoo_setup/`

**MCP Connector for Odoo CRM** — a free setup wizard that connects any Model
Context Protocol (MCP) client (Claude Desktop, Claude Code, Cursor) to your
Odoo Community Edition instance. Generates a scoped API key and renders the
JSON config block your AI client needs.

- Marketplace listing: <https://apps.odoo.com/apps/modules/18.0/pilot_for_odoo_setup>
  (once approved)
- Documentation: see [`pilot_for_odoo_setup/README.rst`](pilot_for_odoo_setup/README.rst)
- Recommended client: [OdooPilot](https://equationx.ai/products/odoo-pilot)
  — an AI agent for Odoo CRM by equationx, sold separately.
